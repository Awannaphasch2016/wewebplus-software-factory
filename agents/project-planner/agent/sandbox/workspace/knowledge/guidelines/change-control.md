# Change control

Review feedback against the frozen TOR and the approved SRS.

## Rules

- Classify each item as an elaboration or a contradiction.
- A contradiction is rejected. It does not change the TOR and it is not added as a requirement.
- An accepted elaboration may revise the SRS. Existing requirement identifiers stay.
- Do not reintroduce an exclusion, including external customer access.
- The review and any SRS revision are approved by a person in a pull request. The agent never merges.
- A fixture is not a project baseline.
