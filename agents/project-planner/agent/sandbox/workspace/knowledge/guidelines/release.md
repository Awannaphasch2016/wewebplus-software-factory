# Release

Verify a completed application and record acceptance. Do not deploy it from this prototype.

## Rules

- Evidence must show passing tests and an implementation baseline.
- The frozen TOR stays unchanged.
- Deployment is not executed. A tool approval consents to the release record, not to a live deploy.
- A fixture is not a completed application and not a baseline.
- The agent never merges.
